# Pasaporte ¡Vámonos! — 스페인어 여행회화 실전 프로그램

다인원격평생교육직업학원(다인에듀) HR 분야 성인 외국어 학습자를 위한 스페인어 여행회화 실시간 인터랙티브 실습 사이트입니다.
교재 *Spanish Phrasebook & Dictionary* (8th ed., 2018)의 챕터 구성을 따라 33개 여행 장면을 연습합니다. 사이트의 연습 문장·설명·퀴즈는 수업용으로 새로 작성했습니다.

## 구성
- **여정 지도**: 6개 파트(출발 준비 · 기초 다지기 · 실전 여행 · 사람과 어울리기 · 안전한 여행 · 맛있는 여행) × 33개 챕터 + 미니 사전
- **챕터별 활동**: 📖 표현 익히기(듣기·음성 인식 말하기) · 🎭 롤플레이 · 🧩 퀴즈 · 🗳️ 우리반 투표 · ✍️ 문장 벽(¡Olé! 좋아요) · 🎯 교재 도표 미션 13종 · 📊 우리반 결과
- **교재 표식**: ⚡ 단축 표현 · ⇄ Q&A 짝 · 👁 Look For · 👂 Listen For · 💡 언어 팁 · 🌍 문화 팁
- **내 여권**: 챕터에서 활동 3개 이상 완료 시 도장(SELLADO)
- **우리반 대시보드**: 방 코드·QR, 종합 순위, 참여자×챕터 히트맵, 파트별 진행률, 강사용 방 초기화
- **🌐 언어 선택**(오른쪽 위): 130여 개 언어로 화면 번역 (스페인어 학습 문장은 번역되지 않음)

## 수업 진행
1. 강사가 `우리반 대시보드`에서 방 코드(예: `DAIN1`)를 정하고 QR/링크를 공유합니다.
2. 수강생은 이름과 방 코드로 입장 → 같은 방의 결과가 실시간으로 공유됩니다.
3. 링크 형식: `https://yalli2.github.io/travel_spanish/?room=방코드`

## 기술
정적 사이트(GitHub Pages). 실시간 공유는 공개 MQTT 브로커(EMQX → HiveMQ → Mosquitto 순으로 자동 전환)의 retained 메시지를 사용하며, 각자 결과는 브라우저에도 저장되어 재연결 시 다시 공유됩니다. 공개 서버이므로 실명·개인정보 대신 닉네임 사용을 권장합니다.
